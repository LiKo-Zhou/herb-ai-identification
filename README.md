# 中药饮片智能鉴定系统

> **版本**: v3.1-feedback (全局 Energy + Top-2 仲裁 + 概率记忆库即时学习)  
> **模型**: ResNet50 Phase 3 (Freeze Backbone + FC 微调)  
> **部署目标**: Firefly ROC-RK3568-PC (Debian 10, 4GB RAM)

---

## 项目简介

本项目是一套基于深度学习的 **129 类中药饮片智能鉴定系统**，集成**品种识别**与**真伪鉴别**两大核心功能。通过摄像头拍摄饮片图像，系统自动识别药材品种并输出《中国药典》信息，同时对疑似伪品给出能量异常告警。

### 核心特性

| 特性 | 说明 |
|------|------|
| 🌿 **品种识别** | 支持 129 类常见中药饮片，验证准确率 **97.17%** |
| 🔍 **真伪鉴别** | 基于 Energy Score 全局异常检测，无需伪品训练数据 |
| ⚖️ **种子类仲裁** | Top-2 后处理仲裁解决麦芽/谷芽等细粒度混淆 |
| 🧠 **即时学习** | 概率记忆库系统，用户纠正后即时生效，无需重新训练 |
| 📱 **交互前端** | 完整 Web UI（欢迎页 → 拍照/传图 → 鉴定 → 药典展示） |
| 🖥️ **边缘部署** | 针对 RK3568 ARM 板优化，~640ms/张，完全离线运行 |

## 系统架构

```
输入图像 (224×224 RGB)
        │
        ▼
┌─────────────────────────────┐
│  ResNet50 Phase 3 ONNX      │  ← 90.6MB，图优化 + 4线程
│  (Freeze Backbone 微调 FC)  │
└──────────────┬──────────────┘
               │
               ▼
        ┌─────────────┐
        │  全局 Energy  │  E = -T·log(Σexp(logits/T))
        │  阈值 21.5    │  ← p95 of all authentic energies
        └──────┬──────┘
               │
      ┌────────┴────────┐
      ▼                 ▼
 E ≤ 21.5           E > 21.5
 (正常)              (告警)
      │                 │
      ▼                 ▼
  返回品种+药典     返回品种+药典+⚠️真伪存疑
        │
        ▼
  Top-2 种子类仲裁（麦芽/谷芽/菟丝子/莱菔子/薏苡仁）
```

### 关键设计决策

- ✅ **全局阈值**：不依赖 Top-1 品类识别正确性，分布偏移下更鲁棒
- ❌ **弃用 PatchCore**：记忆库因分布偏移反而增加 authentic 误报 26-40%
- ✅ **One-Class**：仅需 authentic 样本，无需收集伪品数据

## 核心模块详解

### 1. 种子类混淆仲裁 (`seed_arbitration.py`)

针对麦芽、谷芽、菟丝子、莱菔子、薏苡仁等外形高度相似的种子类药材，在模型输出后增加 Top-2 仲裁逻辑：

- **策略1**：麦芽↔谷芽概率差 < 0.20 → 触发"疑似"警告
- **策略2**：谷芽被错分为菟丝子/薏苡仁/莱菔子，且 Top-2 为谷芽、conf < 0.85 → 触发警告

验证效果：麦芽等效准确率 89.7% → **93.5%**，谷芽 77.6% → **87.3%**。

### 2. 概率记忆库即时学习

利用 softmax 概率向量作为特征指纹：
- 同类别相似度：**1.0**
- 跨类别相似度：**~10⁻¹²**

用户在前端提交纠正后，系统保存该图片的概率指纹 + 正确标签。后续推理时，若输入与记忆库记录相似度 > 0.99，则自动覆盖模型输出。

### 3. 遮挡敏感度可解释性 (`generate_occlusion_map.py`)

纯 ONNX 实现，无需梯度。通过遮挡图像不同区域观察分类概率变化，生成热力图定位模型关注区域。用于回答"模型根据什么判断真伪"的可解释性问题。

## 部署方式

### 环境要求

- Python 3.9+
- Flask
- ONNX Runtime
- NumPy, Pillow

### 快速启动（PC 端测试）

```bash
pip install flask onnxruntime numpy pillow

# 下载模型文件并放入 models/ 目录
# 启动优化版 API 服务
python deploy_board/app_optimized_v3.1_arbitration.py
```

### RK3568 板端部署

```bash
# 通过 ADB 推送部署包
adb push deploy_board/ /opt/herb_ai/upgrade/
adb shell "cd /opt/herb_ai/upgrade && chmod +x install.sh && ./install.sh"
```

部署脚本会自动完成：备份旧版本 → 复制新文件 → 安装依赖 → 停止旧服务 → 启用新服务 → 健康检查。

## 已知限制与后续优化

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 训练数据混入电商水印图 | 实拍大面积失效 | 概率记忆库即时学习 + 数据清洗（进行中） |
| 白芷/当归等 7 味药缺失 | 无法识别 | 未知品种兜底提示 + 增量训练计划 |
| 分布偏移 | authentic 样本错分 | 全局 Energy 阈值 + 记忆库纠正 |
| 板端推理速度 | ~640ms/张 | 已满足交互流程，后续切换 RKNN NPU 加速 |
