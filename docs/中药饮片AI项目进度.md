## 四、部署操作手册

### 方式一：U 盘/SD 卡拷贝（备用）

```bash
# 1. 将 deploy_board/ 所有文件拷贝到 U 盘根目录
# 2. U 盘插入 RK3568
# 3. 板端执行：
mkdir -p /opt/herb_ai/upgrade
cp /media/usb0/* /opt/herb_ai/upgrade/
cd /opt/herb_ai/upgrade/

./install.sh
```

### 方式二：ADB 推送（USB 线连接时可用）

```bash
# PC 端执行：
adb push deploy_board/ /opt/herb_ai/upgrade/
adb shell "cd /opt/herb_ai/upgrade && chmod +x install.sh && ./install.sh"
```

## 八、严重问题记录（2026-05-21 新增）

### 🔴 问题1：训练数据质量灾难性缺陷

**现象**：实拍白芍被识别为天麻（置信度 > 99%）

**根因**：训练数据混入大量**电商图片**，带有文字水印和商品标签
- 白芍训练图：带有红色"白芍"水印 + "精选白芍 正品中药材"底部文字
- 白术训练图：带有顶部横幅文字 + "200g"标签
- 天麻训练图：反而干净（纯药材特写）

**后果**：
- 模型学到的不是药材视觉特征，而是**文字水印和排版风格**
- 实拍图（无水印、自然背景）被模型"不认识"
- 干净的白芍实拍在特征空间中更接近干净的天麻训练图
- 系统性影响：**所有依赖文字水印识别的类别，实拍都会失效**

**缓解措施**：
- ✅ 已部署概率记忆库（即时学习）：用户纠正后，同一样品再次拍摄可自动修正
- ✅ 已添加未知品种兜底提示（置信度<0.5或Energy>21.5时提示）
- ✅ 已禁用不合理的 TTA 垂直翻转

**根治方案**：
- 清洗训练数据：删除/裁剪带水印的图片，或补充纯药材实拍数据
- 重新训练 Phase 4 模型

### 🔴 问题2：白芷、当归等常见中药类别缺失

**现象**：白芷实拍 → 天麻；当归实拍 → 天麻

**根因**：`classes_129.txt` 中**不存在** `baizhi`（白芷）和 `danggui`（当归）

**确认缺失的常见中药**：
| 药材 | 拼音 | 状态 |
|:---|:---|:---:|
| 白芷 | baizhi | ❌ 缺失 |
| 当归 | danggui | ❌ 缺失 |
| 黄连 | huanglian | ❌ 缺失 |
| 黄芪 | huangqi | ❌ 缺失 |
| 川芎 | chuanxiong | ❌ 缺失 |
| 熟地黄 | shudihuang | ❌ 缺失 |
| 桂枝 | guizhi | ❌ 缺失 |

**缓解措施**：
- ✅ 已添加未知品种兜底提示

**根治方案**：
- 收集每类 50-100 张图片
- 增量训练为 131+ 类模型

### 🟡 问题3：分布偏移导致的广泛错分

**现象**：data_authenticity 验证集（不同拍摄条件）大量 authentic 样本被错分
- 党参 authentic → 天麻/人参/丹参/麦冬
- 丹参 authentic → 蒲公英、柴胡、金银花、天麻
- 人参 authentic → 麦芽、金银花、石膏

**根因**：`data_90` 训练集与实拍验证集的**拍摄条件、光线、背景、切割方式完全不同**

**缓解措施**：
- ✅ 全局 Energy 阈值（p95=21.5）可捕获部分偏移样本
- ✅ 概率记忆库可纠正已见过的偏移样本
